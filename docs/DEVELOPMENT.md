# Сборка, тестирование и отладка

## Как выбирается FASM

`tools/fasm/run.sh` принимает ровно два аргумента: исходник и результат. Он
выбирает первый доступный вариант:

1. путь из переменной `FASM_BIN`;
2. `fasm` из `PATH`;
3. официальный статический бинарник из архива на Linux x86_64;
4. локальный `linux/amd64`-контейнер на macOS Apple Silicon.

Зафиксирован архив FASM 1.73.35 и его лицензия. Это устраняет различия между
рабочей машиной и CI. Docker-образ создаётся один раз и остаётся только в
локальном кэше Docker.

## Полная проверка

```bash
make test
```

Команда выполняет три уровня:

1. FASM собирает загрузчик, ядро и raw-диск.
2. `tests/check_image.py` проверяет размеры, `55 AA`, кратность сектору и
   точную конкатенацию файлов.
3. `tests/smoke_qemu.py` запускает x86_64 QEMU в TCG, забирает текст из порта
   `0xE9` и требует маркер `VARANIA:BOOT_OK`. Ядро печатает маркер только
   после первого IRQ0, так что тест охватывает IDT, PIC и PIT.

TCG используется намеренно: он одинаково работает на Mac ARM и Linux и не
зависит от KVM/HVF. Smoke-тест останавливает QEMU сам через 10 секунд.

## Интерактивный запуск

```bash
make run
```

Откроется стандартное окно VGA. Клавиатура поддерживает базовый набор ASCII,
Enter и Backspace. Для текстового запуска:

```bash
./c.sh run \
  -display none \
  -serial none \
  -monitor none \
  -debugcon stdio \
  -global isa-debugcon.iobase=0xe9
```

## Диагностика ранней загрузки

```bash
make debug
```

QEMU пишет `qemu-debug.log` с исключениями и ошибками гостевого процессора.
Полезные симптомы:

- повторяющиеся `Triple fault` — ошибка до рабочего IDT;
- #PF с установленным RSVD — некорректный флаг или выравнивание таблицы;
- отсутствие любого текста `0xE9` — ядро не достигло `print_init`;
- текст до тестовой программы, но без `BOOT_OK` — проверить PMM/VMM и `int 0x30`.

## Правила изменения карты памяти

1. Сначала изменить константы в `src/const.inc`.
2. Проверить, что диапазоны не пересекаются и PTE/PDE правильно выровнены.
3. Обновить резервирование в PMM, если появилась новая служебная область.
4. Обновить таблицу в `docs/ARCHITECTURE.md`.
5. Выполнить `make clean && make test`.

Образ ядра фиксирован на 64 KiB, а IDT начинается со смещения `0xF000`.
FASM остановит сборку, если код и данные вырастут до IDT.

## Добавление прерывания

1. Написать короткий stub, который сохраняет регистры через
   `push_all_registers`.
2. Вызвать обработчик с обычным amd64 ABI.
3. Для IRQ отправить EOI в PIC.
4. Восстановить регистры и выполнить `iretq`.
5. Добавить шлюз в `interrupts_init`; для исключения с кодом ошибки не класть
   синтетический ноль.

## CI

Workflow `.github/workflows/ci.yml` запускает `make test` на Linux x86_64.
Архив FASM берётся из репозитория, а QEMU — из системного пакета runner-а.
