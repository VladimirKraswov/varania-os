# Varania OS amd64

Varania OS — небольшая учебная операционная система на Flat Assembler. Проект
начинался в 2019 году как 32-битное x86-ядро и теперь загружается в **64-битном
long mode amd64**: собственный BIOS-загрузчик, четырёхуровневая адресация,
64-битные IDT/TSS, менеджер физической памяти по карте E820 и простые драйверы.

Это не дистрибутив общего назначения. Главная цель проекта — показать путь от
первого сектора диска до работающего 64-битного ядра без скрытого загрузчика и
стандартной библиотеки.

## Что уже работает

- двухэтапная загрузка с raw-диска через BIOS EDD/LBA;
- переход `real mode → protected mode → long mode`;
- PAE и четырёхуровневые таблицы страниц;
- ядро в верхней половине по адресу `0xFFFF800000000000`;
- текстовый VGA 80×25 и параллельный диагностический вывод в порт `0xE9`;
- 256 64-битных шлюзов IDT, обработчики исключений и отдельный IST-стек для
  двойного сбоя;
- PIC 8259A, PIT 100 Гц и клавиатура PS/2;
- PMM на основе реальной карты BIOS E820, простая куча и динамическое
  отображение 4-КиБ страниц;
- учебный системный вызов `int 0x30`;
- копирование и запуск позиционно-независимой программы в отдельной странице;
- структурный тест образа и настоящий headless-тест загрузки в QEMU.

## Быстрый старт

### macOS на Apple Silicon (M1/M2/M3/M4)

Нужны [QEMU](https://www.qemu.org/download/#macos) и запущенный
[Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/):

```bash
brew install qemu
make test
make run
```

FASM в Homebrew не требуется. В репозитории лежит официальный архив FASM
1.73.35; на ARM Mac он автоматически запускается в локальном
`linux/amd64`-контейнере. Сборочный скрипт ничего не устанавливает в систему.

### Linux x86_64 (Debian/Ubuntu)

```bash
sudo apt update
sudo apt install make python3 qemu-system-x86
make test
make run
```

На Linux x86_64 официальный статический FASM запускается прямо из архива в
`tools/fasm/`, поэтому Docker для обычной сборки не нужен. Если команда `fasm`
уже есть в `PATH`, будет использована она.

### Короткая совместимая команда

Старый `c.sh` сохранён как удобная оболочка:

```bash
./c.sh build
./c.sh test
./c.sh run -display none -debugcon stdio -global isa-debugcon.iobase=0xe9
```

## Команды

| Команда | Назначение |
|---|---|
| `make build` | собрать `BOOT.BIN`, `KERNEL.BIN` и `VOS.VHD` |
| `make check` | проверить размеры, boot signature и структуру raw-образа |
| `make test` | выполнить `check` и загрузить ОС в QEMU без окна |
| `make run` | запустить систему в графическом окне QEMU |
| `make debug` | запустить headless-QEMU с `qemu-debug.log` |
| `make clean` | удалить только три сборочных файла и журнал QEMU |

Успешный smoke-тест должен увидеть строку:

```text
VARANIA:BOOT_OK
```

## Структура проекта

```text
src/boot/                 BIOS-загрузчик: 16, 32 и 64-битные этапы
src/kernel/kernel.asm     точка сборки и вход amd64-ядра
src/kernel/amd64/         активные 64-битные модули ядра
src/kernel/memory/        общий с загрузчиком сбор карты E820
src/kernel/*              исторический 32-битный код для сравнения
tests/                    проверка формата и QEMU smoke-тест
tools/fasm/               воспроизводимый FASM 1.73.35 и его лицензия
scripts/                  запуск QEMU
```

## Текущие ограничения

Система загружается через legacy BIOS, работает на одном процессоре и пока не
имеет пользовательского режима, файловой системы, USB, сети и ACPI. Старые
экспериментальные модули задач, мыши и командной строки сохранены как история,
но не входят в 64-битный образ. Эти ограничения намеренны и перечислены явно,
чтобы следующий учебный шаг можно было выбирать независимо.
