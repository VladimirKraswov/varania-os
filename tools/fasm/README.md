# Зафиксированный FASM

Сборка использует официальный архив Flat Assembler 1.73.35 для Linux:

```text
fasm-1.73.35.tgz
SHA-256: a34dec7d0bc2dc79faabb68bd8bc2f62b6cfb31d69c01449367ce4cd8098934e
```

Источник: [flatassembler.net](https://flatassembler.net/download.php).

На Linux x86_64 `run.sh` извлекает статический бинарник во временный каталог.
На macOS ARM тот же файл запускается в контейнере, описанном `Dockerfile`.
Лицензия FASM воспроизведена в `LICENSE.txt` и также находится внутри архива.

Чтобы намеренно заменить версию:

1. скачать новый официальный архив;
2. обновить имя архива в `Dockerfile` и `run.sh`;
3. обновить версию, SHA-256 и лицензию в этой папке;
4. удалить старый локальный Docker-образ;
5. выполнить `make -B test`.
